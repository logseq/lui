# NSH source support inventory

Generated by `python3 tooling/nsh_support_inventory.py`; check with `--check`.
Use `--json` for every canonical property/event, known property gap, enforced
restriction, conservative unreferenced-property candidate, test location and source hash.

The canonical contract contains **87 kinds**; **84 have an admitted native route**.
The desktop scope requires **85 kinds**, with **1 routes still missing**.
SwipeActions/SwipeAction are explicit mobile-only desktop exceptions; their common wire kinds and maintained mobile implementations remain.
The remainder are explicitly rejected by `render::validate` before publication.
An admitted route is **partial support**, not a claim that all its canonical
properties, events, children or defaults are implemented. Source-listed tests
are not rerun by this generator and do not establish Windows/Linux/macOS parity.

## Verified gaps and priorities

The canonical contract defines the listed properties. The current adapter does
not implement the authored behavior on the indicated routes. The restrictions
below identify known fail-closed values and transitions; remaining gaps need
implementation or explicit rejection with migration notes. Acceptance alone
is not a support guarantee.

- **G1**: Authored style-class has no adapter reader; native/style defaults remain. Candidate properties: `style-class`.
- **G13**: Authored layer alignment remains unimplemented outside local Overlay. Candidate properties: `alignment`.
- **G11**: Command shortcut hints are not forwarded; built-in icons, placement, size and variants have native bindings outside tabs. Candidate properties: `tooltip-keys`.
- **G3**: Textarea Enter behavior is forwarded through native SubmitBehavior. Single-line inputs keep native submit/blur defaults; Authored blur submission uses native focus/composition with Enter deduplication; focused unmodified Up/Down forwards native navigation requests; color input remains rejected; valid 24-hour time uses native TimeField, preserving precision, change and submit events without replacing its native input. Empty/invalid times and unavailable editing options fail preflight. Other input hints and full NavigationKey require review. Candidate properties: `input-type`.
- **G4**: Checkbox routes forward checked/indeterminate/disabled/label; authored indicator/detail behavior remains absent. Candidate properties: `checked-indicator-border-color`, `indicator-border-color`, `label-opacity`, `toggle-detail-enabled`.
- **G5**: Image forwards canonical URL, alt/label, fit, eager/default loading and native Load. Resource IDs, crop rectangles and authored referrer policy are explicitly rejected; loading=lazy is a value restriction listed separately, not a missing eager-loading path. Candidate properties: `image`, `referrer-policy`, `source-height`, `source-width`, `source-x`, `source-y`.
- **G8**: Container appearance and CSS list markers are not implemented by the Scroll/VirtualList routes. Candidate properties: `list-style`, `style`.
- **G9**: Full NavigationKey payload remains unimplemented on generic calendar/container key handlers. Candidate properties: `navigate-enabled`.
- **G14**: Canonical pointer-capture remains unimplemented. Candidate properties: `pointer-capture`.
- **G12**: Typed native behavior components do not expose generic root pointer/gesture projection; unit semantic events remain supported separately. Candidate properties: `double-press-enabled`, `long-press-enabled`, `pointer-enabled`.
- **G10** is retired for current generic host routes: authored activation is now installed with live guards. Radio's true press-enabled value remains explicitly rejected.

Priority 1: remaining typed-control pointer/modifier delivery, navigation
and capture; remaining input hints; authored checkbox indicators; image resources/crop;
menu-item icons. Priority 2: remaining appearance, class translation or explicit
rejection, list appearance and metadata.

## Event, child and default limitations

- Native host routes deliver available modifier/pointer payloads; typed behavior
  components still expose unit events and do not gain a synthetic observer wrapper.
  The JSON event-path list is not a claim of full per-field parity. Appearance
  uses the actual existing ref after native materialization, including disabled
  controls; it is not an OS-visible-frame notification.
- Scroll forwards a static horizontal axis to native Scroll.horizontal; absent or
  explicit vertical uses its native default. Axis changes require a new keyed
  node, while ordinary edits preserve native content/offset/editor identity.
- FilePicker uses native paths and exact request tokens; cancellation emits Dismiss,
  results/errors emit Picked. Busy requests do not queue or replace the dialog.
  Headless service tests and a real OCaml Picked/Dismiss ABI test are mapped;
  they do not qualify actual operating-system dialog UX.
- MediaSurface uses native Video with controls and native playback defaults.
  URL updates retain the player; playback errors are nonfatal renderer diagnostics.
  Its tests inspect native properties and identity, not actual media decoding.
- Tree delegates keyboard, selection, expansion, Action and virtualization to NSH.
  Metadata projection/flattening is O(n); mounted rows are viewport-bounded.
  Native SelectedChange/Expand/Collapse/Action target metadata callbacks; these
  are not Tree-root event transports. No custom Tree focus controller is used.
- Toast uses native lifecycle: 400ms entrance, then its TTL, then 200ms exit.
  Hover/focus pause the native manager. Dismiss follows completion; a retained
  closed incarnation stays closed until replaced. No application close veto exists.
- Input change/submit and Checkbox toggle callbacks now honor live callback
  flags and enabled state. Row/Column/Box use one native-ref focus transition
  owner rather than duplicate direct Input focus handlers.
- Host listeners are installed from authored initial capabilities. Enabling an
  initially unauthored press/pointer/gesture capability after mount is explicitly
  rejected atomically pending a public identity-preserving rebind path. Focus-within
  flags on the three canonical containers can change live. Unused Text nodes get
  no press listener, so they do not steal activation from enclosing commands.
- Core text routes render the node's text value and discard their canonical
  children. Container admission therefore does not prove rich/composed text.
- Heading uses the same retained native Text host with Header role and live
  accessibility_level. Its absent level is 2, preserving the replaced desktop
  default; the canonical constructor writes only authored levels. Apple defaults
  to 1 and Web forwards authored aria-level, so no common wire default is inferred.
  Levels 1..6 use native 3xl/2xl/xl/lg/base/sm presets with bold weight; authored
  typography and color win. At the native default scale these are 30/24/20/18/16/14
  points, replacing the old desktop 28/26/24/22/20/18-point formula. Text supplies
  the accessible name; Heading still rejects the noncanonical accessibility-label.
  The mapped Headless tests cover level/default/override/identity/rollback behavior,
  not operating-system screen-reader announcements or native screenshot metrics.
- MenuItem binds icon/check/shortcut parts, native sizing/selection placement and
  variant styling. Authored foreground wins over native checked/hover defaults.
  This inventory does not infer canonical absent-property defaults from NSH's
  defaults. Those need explicit cross-backend behavior tests and migration notes.
- Button/toggle command icons use shared Web SVG assets, native retained size/variant
  bindings and decorative glyph accessibility. Tab appearance, application icon
  registration and shortcut hints still need qualification or implementation.
- Native pointer states used by styles are separate from LUI pointer events.
  Paint::read dynamically handles prefixed background/foreground/border/opacity/
  shadow properties; the generator excludes these string-search false positives.

- Image uses canonical url and live native source/fit/name bindings. Default fit
  is stretch, fit means contain and fill means cover; an accessibility label wins
  over alt. Successful native decoding emits Load through the existing C ABI.
  The mapped headless tests check defaults, retention, stale incarnations and
  atomic rejection; the real OCaml test dispatches an explicit Load. Neither
  establishes native decoding, HTTP transport or screenshot/pixel fit accuracy.
  Native decoding has a separate test_nsh_image_app.py packaged-app qualifier.
- Drawer uses a controlled left Sheet: selected remains application owned;
  Escape/backdrop requests toggle-changed only when enabled and toggle-enabled.
  It introduces no separate dismiss transport. Its retained main editor survives
  open/close and sidebar replacement in the mapped focused test.
- Resizable uses native ResizeHandle capture with local bounded width. Authored
  width changes reset it; unrelated edits preserve the user's width; min/max
  updates clamp it. There is no resize-value callback in its canonical API.
  Existing-root accessibility actions use 16-point steps; native keyboard arrows
  and consolidated handle accessibility semantics are not established by the drag test.
- EdgeInset preserves the first/main child and reserves measured space for
  later/pinned children at top/bottom/leading/trailing. Logical edges follow RTL;
  pooled padding/paint belongs to pinned content, not the main host. visible=false
  returns pinned space while retaining native child identities. The appearance
  visibility test is listed because its declaration exists; this generator
  does not run it or qualify a native visible-frame notification.
- BottomTabs uses separate native Tab triggers and lazy retained keyed pages.
  The first source-selected child wins, else the first child even when disabled.
  Unvisited pages are not materialized; visited hidden pages retain native editor
  identities, drafts and scroll offsets. Page Buttons remain ordinary Buttons.
  Scoped Appear follows each visible transition rather than body-only edits.
  The mapped source tests do not by themselves qualify OS focus, IME or pixels.
- Breadcrumb/Pagination keep authored children under native Toolbar roving focus;
  focus movement does not itself activate them. Gap/main/cross reach the child row.
  Breadcrumb separators follow keyed child positions without remounting editors.
  These are authored-child adapters, not a flattened native data-owned pagination API.
- Stepper derives Step state from keyed source positions and required nonnegative active.
  Earlier/current/later positions are completed/active/pending; out-of-range active
  values remain representable. Native semantics expose the current step without
  synthesizing a selection callback. Timeline uses retained native hosts: icon wins
  over indicator text, then a dot; connector defaults true; selected/variant/title/
  description/meta remain live. TimelineItem preserves canonical native pointer
  payloads through NativeEvents instead of substituting a unit-event-only Button.
- Split uses native ResizablePanelGroup and keyed ResizablePanel children.
  Absent sizes are equal; first-pane-width and pane min/max are absolute points.
  User drags persist without model echo and report ValueChanged once at completion.
  The native 9-point adjustable band owns capture and 10-point AT adjustments;
  no legacy ratio solver, keyboard-arrow controller or close/refusal policy remains.
  Programmatic sizing and keyed pane/editor retention have mapped source tests.
- ListItem flat/disclosure composition preserves retained body and nested-row
  identities. Its mapped rejection/rollback tests do not establish inline editing,
  rich typed activation details, long/double press or Return-only submission.

## Explicit restrictions already enforced

Unsupported kinds; box display=contents; any authored white-space; true inert;
nonzero container-relative-frame-inset; radio press-enabled=true; grid count
above u16; virtual count above u32; unanchored tooltips; menu-role external
popovers; nonzero popup alignment offset; invalid/mutated popup anchor source;
menu-trigger icon and invalid menu shape; same-incarnation toolbar axis changes.
Enabling an initially unauthored host event listener capability after mount also
requires an explicit remount. See render::validate,
validate_popup_shape, controls::validate, virtual_rows::validate and style::compile.

- `context-menu`: Attaches to one retained Button or ListItem; changing attachment mode on the same incarnation requires a new keyed host.
- `file-image`: Local paths or file URLs only; max-pixel-size is 1..4096, default 1024. Encoded input above 64 MiB fails decoding.
- `file-picker`: Only native files/folders dialogs; photo-library/camera sources and completion leases are rejected. File filters accept extension groups, not MIME or UTI filters; folders use native folder options.
- `media-surface`: Requires a nonempty URL; foreign surface resource IDs, including zero, are rejected.
- `tree`: Children are native item metadata, not arbitrary view/editor bodies; unsupported metadata properties and pointer callbacks are rejected. Use tree_item semantic selection/expansion/action callbacks; legacy pointer-enabled rows are rejected.
- `input`: input-type=color is rejected; time uses native TimeField for valid HH:MM/HH:MM:SS and rejects unsupported editing options; text blur/navigation observers require authored mount-time capability.
- `text-field`: Blur/navigation capability must be authored at mount; full NavigationKey is not implemented.
- `secure-field`: Blur/navigation capability must be authored at mount; full NavigationKey is not implemented.
- `search-field`: Blur/navigation capability must be authored at mount; full NavigationKey is not implemented.
- `textarea`: Blur/navigation capability must be authored at mount; full NavigationKey is not implemented.
- `scroll`: Orientation is native horizontal/vertical at mount; changing its effective axis on the same incarnation is rejected atomically.
- `drawer`: Requires exactly two canonical children: sidebar first and main content second.
- `split`: Requires exactly two canonical pane children; sizes and resize events use absolute points. Rejects ratio value, custom resize-handle-width, nonzero resize-handle-offset and pointer-enabled=true. Rejects nonzero resize-duration and authored resize-easing/resize-origin; uses the native 9-point handle.
- `edge-inset`: At most 32,760 children because native grid line indices use signed 16-bit values. Rejects any authored hover-*, pressed-*, focus-*, selected-* or disabled-* pooled state-paint property. Rejects opacity other than 1, nonempty shadow other than none, and any authored transition.
- `list-item`: Rejects change-enabled=true inline editing and true long-press-enabled, double-press-enabled or submit-enabled callbacks. Adding or removing expanded within the same incarnation is rejected; switching flat/disclosure mode requires a new node incarnation.
- `avatar`: Rejects authored image resources until the native image-resource bridge is available.
- `image`: Rejects any authored image resource ID, including zero and IDs supplied alongside a URL; use canonical url. Rejects any authored source-x/source-y/source-width/source-height crop rectangle property. Rejects loading=lazy; eager/default uses the native loader. Rejects any authored referrer-policy; the native transport's default policy remains.
- `link`: Without an authored press handler, URL navigation requires a valid external system URL; relative destinations are rejected.

These restrictions reject the entire transaction before publication, preserving
accepted state and generation for a corrected retry.
